# Connect & Thrive

Build us a Postgres-backend React app that can be deployed on Heroku and lets a community or organization define a tech need based on the following tech assessment: https://share.gemini.google/qp5VuIhpxKqx.  That can present the results of multiple forms they've submitted over time on a timeline connected by a progress bar. After each organization assessment is completed, publish it to a dashboard where businesses, independent contractors, or small businesses can compete by providing a solution to the organization's needs through a business assessment. The expected result will be implementation documentation, a checklist to hand off to the organization, and a final knowledge base with confirmation that both parties have met their obligations.
